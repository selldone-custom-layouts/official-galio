# Galio Sundae — Selldone Layout

**Galio Sundae Patisserie** (package `galio-sundae-patisserie`, first version `1.0.0`) is the fourth Layout of the Selldone shop **Bakio** (shop 15740, xapi name `bakio`, `https://bakio.myselldone.com`): one pâtisserie at 1 The Embarcadero, San Francisco, selling individual pastries for courier delivery, worldwide shipping and pickup, cash on delivery, guest checkout. Single seller, English only, USD only. It is built for its own domain, **galio.selldone.shop**; the shop default (Layout 36, Bakini Noir) and domain 1247 are never changed by this Layout.

The design is mockup set **B, "Sundae"** (`../galio-design/home-b.html`, its source in `g/{core.css,b.css,home.js,icons.js,photos.js,theme-color.js}`, screenshots in `shots/`): a sorbet-coloured pastry parlour whose sections follow Qode's Glace ice-cream shop theme. Build brief: `../galio-design/BUILD-GALIO.md`. The inner pages' mockups (`../galio-design/<page>-b.html`) are drawn by another session (brief `BRIEF-GALIO-PAGES.md`) and are ported in phase 2.

It started from Bakini Noir 1.0.5 (`bakini-layout`, `git clone`, history kept), so every Selldone flow Noir solved is kept: the bag, checkout, address and map sheets, payment, order, account and sign-in, the blog, compare, the i18n runtime and `t()` with Arabic right to left, the region pill, the theme switcher row, fit-in-circle, the release scripts and the live checks.

**Files.** `vite.config.ts` `coreChunk`: a module of **the Layout's own source** (this folder, never `node_modules`, never a virtual or query module) under 6 kB whose static imports are already in the core (or join it) joins the core instead of becoming its own file, and the reading pages (`pages/official|blog|faq|errors`, `components/galio/read`) share one file (`galio-read`). Release 1.0.1 has about 317 files (Noir 1.0.5: 360) and no chunk imports `shop.js`. Rollup's `experimentalMinChunkSize` is not used: it merged chunks into the entry. In 1.0.0 the rule took any small module, packages included: Prism's language files (`prismjs/components/prism-*.js`, no imports of their own, so they passed the test) joined the core and ran before Prism, `ReferenceError: Prism is not defined` stopped the entry and galio.selldone.shop stayed blank. `GALIO_CHUNK_LOG=<file>` writes the list of modules that joined the core.

**The production build is loaded before every upload** (`scripts/galio-prod-check.mjs`, step 5b of `scripts/release.sh`, which stops the release on failure). A local server answers every address with the shop's real storefront HTML (from `SHOP_URL`, default galio.selldone.shop) whose Selldone loader is pointed at `dist/app/shop.js` and `shop.css` (served from `http://localhost:9146/__galio/app/`, the loader's `local` switch allowing http); headless Chromium opens the home and moves in the app to a collection, a product, the journal, a post, the bag with one piece and the checkout. Each page must draw `.gl` with text and raise no page error. Run by hand: `npx vite build` then `node --use-system-ca scripts/galio-prod-check.mjs`.

**Lesson (14 Nov 2026): dev checks never see chunking bugs — always load the built bundle before uploading.**
